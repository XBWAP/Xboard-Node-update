支付系统 API 对接文档

Version 2.0 · 正式稳定版
统一支付网关接口规范 · 支持微信/支付宝 · 同步异步回调 · 安全签名机制
🔐 通用安全机制

通讯方式： HTTP POST / GET  |  数据格式： application/x-www-form-urlencoded  |  字符编码： UTF-8

⚠️ 通讯密钥 (AppKey)
每个商户拥有唯一通讯密钥，用于签名校验。请妥善保管，切勿泄露至前端或公开仓库。
🔏 签名算法 (MD5)
大多数接口签名采用 MD5(参数拼接字符串 + 通讯密钥)，具体参数顺序以各接口说明为准。大小写敏感，生成32位小写MD5。
📌 创建订单签名示例：
拼接原文：1547129707139vone66620.1a7cc8678193ee9c70ae3d75fd04ae6a9
计算结果：2b8b5d58c51203162f14939bdbc46a54
📝 1. 创建订单
POST/GET /createOrder

生成支付订单，返回二维码链接或跳转支付页。

参数类型必填说明
payIdstring必传商户订单号，唯一（建议时间戳+随机）
typeint必传1=微信支付，2=支付宝支付
pricefloat必传订单金额（元）
signstring必传签名：md5(payId + param + type + price + 通讯密钥)
paramstring可选自定义参数，回调时原样返回
isHtmlint可选1=自动跳转支付页面，0=返回JSON数据（默认）

✅ 成功响应示例

{
  "code": 1,
  "msg": "成功",
  "data": {
    "payId": "1547129707139",
    "orderId": "201901102220147500",
    "payType": 2,
    "price": 0.1,
    "reallyPrice": 0.1,
    "payUrl": "HTTPS://QR.ALIPAY.COM/FKX03500Z2ZYWA0ELYUB5D",
    "isAuto": 1,
    "state": 0,
    "timeOut": 5,
    "date": 1547130014777
  }
}

📦 返回字段说明

字段类型说明
codeint1成功，-1失败
msgstring提示信息
data.orderIdstring云端订单号（后续查询关键）
data.payUrlstring支付二维码内容（或链接）
data.stateint-1过期 0待支付 1完成 2支付完成通知失败
data.timeOutint订单有效分钟数
🔍 2. 查询订单信息
POST/GET /getOrder
参数类型必填说明
orderIdstring必传云端订单号（创建订单返回）

响应格式 同创建订单data结构，额外包含订单完整信息。

{
  "code": 1,
  "msg": "成功",
  "data": { "payId":"...", "orderId":"...", "state":0, "price":0.1, ... }
}
✅ 3. 查询订单支付状态
POST/GET /checkOrder
参数类型必填说明
orderIdstring必传云端订单号

已支付响应示例

{
  "code": 1,
  "msg": "成功",
  "data": "https://yourdomain.com/callback?payId=xxx¶m=xxx&type=2&price=0.1&reallyPrice=0.1&sign=xxx"
}

字段说明： code=1 表示已支付，data为支付完成跳转地址（含回调参数）；code=-1 表示未支付或失败。

🔒 4. 关闭订单
POST/GET /closeOrder
参数类型必填说明
orderIdstring必传云端订单号
signstring必传签名：md5(云端订单号 + 通讯密钥)
 
{"code":1,"msg":"成功","data":null}

订单关闭成功则无法继续支付，适用于超时或用户取消场景。

❤️ 5. 查询网关状态 & 监控端
POST/GET /getState
参数类型必填说明
tlong必传当前时间戳（毫秒）
signstring必传签名：md5(时间戳 + 通讯密钥)
 
{
  "code": 1,
  "msg": "成功",
  "data": {
    "lastpay": "1547394640856",
    "lastheart": "1547613873755",
    "state": "1"
  }
}

state: 1=在线，0=掉线，-1=未绑定监控端。
lastpay/lastheart 均为毫秒时间戳，可辅助监控系统健康度。

🔔 6. 异步回调 & 同步跳转

用户支付成功后，系统会向您的后台设定的异步通知地址发送GET请求；
若创建订单时 isHtml=1，还会同步跳转至您指定的通知页面。

回调参数列表
参数说明
payId商户订单号
param自定义透传参数
type1微信 2支付宝
price订单金额
reallyPrice实际支付金额
sign校验签名：md5(payId + param + type + price + reallyPrice + 通讯密钥)

处理要求：
接收回调后务必重新计算sign比对，验证通过后输出纯文本 success（不含额外字符），系统即停止重试；
如返回非success，系统将会间隔重试通知（通常重试5次）。

PHP回调示例代码

<?php
$key = "83d551f0b3609781a22536ca2658473d"; // 您的通讯密钥
$payId       = $_GET['payId'];
$param       = $_GET['param'];
$type        = $_GET['type'];
$price       = $_GET['price'];
$reallyPrice = $_GET['reallyPrice'];
$sign        = $_GET['sign'];

$_sign = md5($payId . $param . $type . $price . $reallyPrice . $key);
if ($_sign !== $sign) {
    echo "error_sign";
    exit;
}

// 业务逻辑: 更新订单状态，增加流水等
echo "success";
?>
💡 最佳实践
  • 收到回调后建议先验证签名，再处理幂等逻辑（防止重复通知）
  • 异步回调地址必须直接返回纯文本 success，避免重定向或HTML包裹
  • 推荐在订单创建时记录云端 orderId，便于后续主动查单补偿
⚠️ 附录：状态码速查
code含义常见场景
1成功/已支付创建订单成功、支付查询已支付、回调成功
-1通用失败参数错误、签名错误、订单不存在、支付未完成
订单状态 state=-1订单过期超出timeOut未支付，需重新创建
订单状态 state=2支付完成但通知失败可主动调用查询接口或手工补单
📌 签名注意： 所有拼接参数时，如果字段为空字符串则按空串处理，必须严格按照接口文档顺序拼接（创建订单按 payId+param+type+price+key）。
